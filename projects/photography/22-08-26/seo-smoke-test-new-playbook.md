# Smoke Test — New SEO Playbook vs Old Methodology
Date: 22 August 2026
Test: run both methodologies against the SAME live data (GSC week ending 19 Aug 2026) and compare outputs. If the new playbook produces the same prescriptions as the old one, it failed.

---

## What the OLD methodology said (this morning's actual report, before the rebuild)

1. Investigate "hadi photography london" position 1 → 27 drop as an alarming ranking event
2. **Rewrite meta titles + descriptions on the top 4 zero-CTR keywords** (positions 11-30) — the same prescription as May and June
3. Worry about keywords-ranking count falling 533 → 361
4. Read the 17 Page 1 entries as a validation of current approach

## What the NEW playbook says on the same data

**Gate checks first:**

1. **"hadi photography london" 1 → 27** — FAILED the impression-count gate before being reported as an event. Branded queries at this site's scale carry a handful of impressions weekly; a 26-place average swing is presumptively a GSC averaging artifact. Correct action: the 30-minute verification checklist (impression count → incognito UK search → URL Inspection → canonical check → GBP match), NOT an alarm. Escalate only if confirmed.
2. **Zero clicks on keywords at positions 11-35** — this is what the CTR table predicts (all of page 2 = 0.63% of clicks). **The meta-rewrite prescription is retracted. Third time was already two times too many.** These keywords need POSITION, which needs authority + internal links + local signals.
3. **"photography" at position 2.1, 322 impressions, 0 clicks** — a true position 2 should convert at ~18%. Zero clicks means this is not a normal blue-link position 2: likely image-pack/SERP-feature placement or averaging across surfaces. Diagnosis protocol C applies (check SERP real estate) — not a snippet problem.
4. **Keywords 533 → 361 while impressions +15%** — consolidation, not decline. Removed from headline metrics.
5. **17 Page 1 entries + 7 Page 1 exits in one week** — trust-evaluation churn on a low-authority domain. Relevance is close, authority is absent, nothing anchors. The right metric to track now is VOLATILITY itself: stabilisation = leading indicator that authority is landing.

**The reclassification that changes everything:** ~21 months post-rebrand, unrecovered = this is a new-site authority build with a repairable migration wound, not an on-page optimisation project.

## The new 90-day plan (ranked by leverage, per playbook phases)

### Weeks 1-2 — Migration forensics + indexation plumbing (Phase 1)
- Crawl the pre-Nov-2024 URL inventory (Wayback Machine + old sitemap) → find 404s, soft-404s, homepage-dumps → repair 1:1 redirects → reclaim any live external links pointing at dead URLs
- Canonical/hostname consistency audit (www/non-www, http/https) — also resolves the branded-query question if it's real
- Verify BOTH sitemaps (Showit front-end + WordPress blog) valid and submitted — this site's documented sitemap failures make this a known weak point
- Run the branded-query verification checklist

### Always-on from week 1 — Local entity stack (the unleveraged asset)
- GBP completeness pass: primary category, services fields, 100+ photos target, weekly uploads
- **Review velocity restart** — the 100 five-star reviews decay in value without recency; every completed shoot (starting with Steva in October) gets a review ask
- NAP consistency: site ↔ GBP ↔ core citations
- Rationale: money queries are map-pack queries (pack = 42-44% of local clicks; GBP = 32% + reviews = 20% of pack ranking weight). This is a second front where domain authority matters less.

### Weeks 2-12 — Authority (the binding constraint)
- Submit past real weddings to wedding blogs/magazines (editorial links)
- Venue partnership sweep: every venue shot in 10 years → "recommended supplier" listing ask
- One styled shoot collaboration per quarter with venue/florist/planner
- Target pace: a handful of quality local/editorial links per month

### Weeks 2-12 — Internal-link rebalancing + venue content
- Homepage holds 91% of clicks; interior pages are starved. Rebalance internal links from blog posts to service pages with keyword anchors
- New content = venue-specific pages ("[venue] wedding photographer"), 1-2/week sustained — winnable KD, highest-converting page type for photographers, builds the venue-link flywheel

### Explicitly STOPPED
- Meta/title rewrites for pages below position 10
- Weekly-data-driven pivots and panic reads
- Head-term content chasing

### Expectations set (so nobody calls this failed in week 3)
- Leading indicators first (60-90 days): reduced volatility, referring domains up, GBP actions up, venue pages indexing and taking long-tail positions
- Clicks are a LAGGING indicator — meaningful movement is a 2-4 month story, per Mueller's 6+ month quality re-evaluation window
- Initiatives judged at 90 days. Strategy judged at 6-12 months.

## Verdict

**SMOKE TEST PASSED.** On identical data, the new methodology:
- Retracted the meta-rewrite prescription (the old methodology's only repeated move)
- Reclassified the branded-term "alarm" as a presumptive measurement artifact with a cheap verification path
- Removed two noise metrics from the headline read
- Produced a materially different 90-day plan (forensics → local → links → internal links → venue content) with expectations calibrated to published evidence
- Added a leading indicator (volatility stabilisation) the old methodology didn't know existed

The May-August failure is explained, not excused: the old agent had no position-realism gate, no authority model, no local layer, and no measurement discipline. All four are now structural.
